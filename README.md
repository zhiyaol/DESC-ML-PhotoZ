# DESC-ML-PhotoZ
   \n\nIn **Training-final.ipynb** and **Analysis-final.ipynb**, we apply and validate a Machine Learning Redshift Estimation algorithm to produce photometric redshift estimations for the simulated extragalactic catalog with magnitude errors *(cosmoDC2_v1.1.4_small_photoz_magerr_10y)* in LSST Dark Energy Science Collaboration (LSST DESC). We study the accuracy of our method using the known redshifts (also referred to as specz) in the cosmoDC2 simulations. We find that our methodology provides accurate sample redshift distributions. The difference between the estimated testing set mean redshift and the true value is (0.2 ± 1.2)*10-4, which is consistent with 0.
